# 轻光影 Lite

NCLR / Horizon 用的低配光影包（Horizon 自有 WGSL 着色器格式，shader API 0.2）。

## 它做什么

| 部分 | 效果 |
| --- | --- |
| 天空 | 天顶更深、地平线更亮；日出日落时太阳周围有一圈暖色；夜里天空留一点深蓝，不再死黑；下雨时整体压暗 |
| 地形 | 保留原版方块光/天光作为环境光，再按面的朝向叠一层太阳（夜里是月亮）方向光；发光方块（火把、岩浆、萤石）额外提亮一点，交给泛光 |
| 实体 | 与地形同一套光照，怪和玩家站在阳光里会和脚下地面一样亮；保留受伤闪红和眼睛/监守者发光 |
| 水面 | 掠射角出现天空反光（菲涅耳），太阳方向出现一条高光 |
| 太阳投影 | 在屏幕空间里沿太阳方向对深度缓冲做 9 步行进，得到地形与实体的投影；半分辨率计算 + 4 tap 模糊，不额外渲染一遍场景 |
| 泛光 | 半分辨率 8 次采样，只让真正亮的东西（太阳、岩浆、火把）溢出光 |
| 合成 | 高光柔肩、轻度 S 曲线、饱和度、暗角 |

## 为什么"低配"

- **没有阴影图**：不重建场景、不额外绘制地形；投影来自已经画好的深度缓冲。
- **两个半分辨率 pass**（投影 + 泛光）+ 一个全屏合成 pass。
- 影子只来自屏幕内能看到的物体——这是屏幕空间投影的取舍，换来手机也能跑。
- 光影选项里的"太阳投影"可以关掉，关掉就只剩方向光和泛光。

## 安装

- 随 NCLR 安装：首次启动会复制到 `Documents/shaderpacks/horizon_lite`，光影页里一键启用，并可切流畅 / 均衡 / 精致。
- 手动：整个 `horizon_lite` 文件夹放到 `shaderpacks/`，或在游戏里 选项 → 视频设置 → 光影 → 光影包 选中它。

## 选项

阴影（太阳投影）、阳光强度、泛光、水面效果、饱和度、暗角；游戏里打开"光影选项"调。
