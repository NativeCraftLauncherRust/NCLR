# 用户界面功能

Last reviewed 2026-11-28

## SwiftUI 侧边栏

- `ios/NCLRSidebar.swift` 实现品牌、六个导航按钮和账号入口，由 `NCLRSidebarController` 托管。
- 品牌固定在顶部，账号固定在底部，中间导航独立滚动。导航按钮最小高度为 52pt，文字跟随系统字号。
- 品牌按内容高度布局，与首个导航按钮之间保留 40pt。侧边栏延伸到底部边缘，账号按钮距底部 8pt。
- 品牌与账号背景使用同一主题底色，在内容边缘以 32pt 的透明渐变连续淡出。首尾导航滚动目标包含 32pt 占位，默认及返回主页时避开渐变。减少透明度开启时使用实色背景。
- 导航和账号点击通过回调交给 `ios/main_l1.m` 的 `showPage:`，账号名称和头像由原有认证状态更新。
- 选中背景通过 SwiftUI 行锚点定位单个 Core Animation 图层，使用刚度 280、阻尼 26 的位置与尺寸弹簧动画，时长由弹簧稳定时间决定，并请求屏幕支持的 60–120Hz 范围，响应系统减少动态效果设置。导航按需滚动到可见区域。

## iOS 启动器页面转场

- 入口文件是 `ios/main_l1.m`。
- `NCLRRootController` 管理侧边栏导航、页面控制器和内容区域。
- `NCLRPageTransitionCoordinator` 负责右侧内容快照、Core Image 动态模糊和清理。
- 页面索引决定上下方向。首次页面安装和当前页面重复点击不播放页面转场。
- 页面转场时长缩短 20%，普通进入为 0.336 秒、退出为 0.096 秒、进入延迟为 0.072 秒，模糊为 0.216 秒。减少动态效果时进入为 0.192 秒、退出为 0.064 秒。
- 设置页的「页面切换模糊效果」使用 `NSUserDefaults` 保存，默认关闭。
- 设置页外观选项提供「跟随系统」「深色」「浅色」，新安装默认跟随系统。
- 设置页「资源下载」提供 1 到 8 路并发，默认 4 路，保存到 `NCLRResourceDownloadConcurrency`。
- 设置页包含外观、资源下载、界面动效、关于、触控界面和清除本地启动器数据入口。
